# Руководство исполнителя: убрать технические дубли (шингл 9) в одном готовом тексте

Рабочая папка: `C:\Users\Lenivec\Desktop\leadscount\Генератор текстов` (PowerShell, Windows; `$env:PYTHONIOENCODING='utf-8'`). `<RUN>` — имя запуска, например `longfu88-app-sg-v01`. Менять можно только файлы своего `<RUN>` (через инструмент ниже). Код, ТЗ, чужие запуски и главные страницы не трогать.

## Что такое технический дубль и зачем это
Технический дубль — 9 и более слов подряд в том же порядке, которые есть в другом тексте (шингл 9; регистр, знаки препинания и разметка не считаются, слова через границы предложений и ячеек таблицы идут подряд). Тексты 12 сайтов одного бренда по одной теме не должны делить такие отрезки ни друг с другом, ни с текстами двух других типов страниц, ни с 12 главными страницами. Сейчас в каждом тексте 50–75 % слов лежат в общих отрезках: их надо переписать своими словами.

## Инструмент
```
python tools/longfu88/dedupe.py report <RUN>                      # общие отрезки по блокам, с предложением вокруг
python tools/longfu88/dedupe.py apply <RUN> <bNN> <файл>          # проверить новый текст блока, записать, пересобрать шаг 4, показать, что осталось
python tools/longfu88/check_answer.py <RUN> <файл> --block <bNN>  # стилевые предупреждения (слова-штампы, «you», вопросы вне FAQ ...)
```
Порядок работы:
1. `report` → список блоков с общими отрезками.
2. Для каждого такого блока перепиши тело блока целиком (заголовок не пишется) в файл `runs/<RUN>/llm/dd_bNN.txt` (инструмент Write, UTF-8) и примени `apply`. Если `apply` пишет FAIL (размер, ключи, формат, язык), поправь тот же файл и повтори. Если после `apply` в блоке остались общие отрезки — перепиши ещё раз, пока их не будет ноль (проверяются все остальные тексты, они меняются параллельно).
3. В конце `report` для своего запуска должен показать `0 shared runs`. Проверь `check_answer.py` для блоков, которые менял (предупреждения `warn` убрать, кроме `info` и слова из ТЗ).

## Правила переписывания
- **Факты не меняются**: все числа, суммы, проценты, сроки, названия предложений, программ, платёжных методов и условия остаются; ничего не добавлять и не додумывать (нет выводов, оценок, советов «лучше всего», обещаний, утверждений о легальности в Сингапуре, приложения-APK и т. п.). Дословная цитата из базы не обязательна: переформулируй (например, «188% up to €2,088 + 18 Free Spins; 25x deposit plus bonus, 40x Free Spins winnings» можно передать другим порядком и словами, сохранив все числа и условия).
- **Не синонимы по одному слову, а другая конструкция**: другой порядок мыслей, другие подлежащие и связки, разбить или склеить предложения. Каждый шаг списка (регистрация, вход, установка ярлыка и т. д.) формулируй по-своему, но шаги остаются шагами (нумерованный список остаётся нумерованным). Одинаковые стандартные фразы, которыми пользуются все 12 тексты («The casino is for players aged 18 or over, and this page is written for players from Singapore», «not a store app», «tap Share and choose Add to Home Screen» ...) в каждом тексте должны звучать иначе.
- **Таблицы и списки**: формат блока (`formats` в `runs/<RUN>/01_brief.json`) сохраняется — таблица остаётся таблицей, список списком. Заголовки столбцов и порядок столбцов можно менять, значения ячеек можно излагать другими словами (но числа и названия остаются). Строки соседних ячеек образуют общий отрезок, если значения совпадают дословно: меняй формулировку условий («30x deposit plus bonus» → «wagering of 30 times the deposit and bonus»).
- **Ключи и бренд**: количество каждого ключа в блоке должно остаться точным (инструмент `apply` проверяет); «Longfu88» в первом предложении вступления остаётся (по нему ставится ссылка на главную). Формы «Longfu88 bonuses», «Longfu bonuses», «Longfu88 promo codes» считаются ключами: не писать.
- **Ссылки**: фразы из `internal_links` в `runs/<RUN>/05_affbulk_config.json` (поле `anchor`) должны остаться в тексте дословно в том же блоке (сохрани их или перенеси в тот же по смыслу блок).
- **Тон и стиль**: английский, третье лицо, нейтрально-информационный, без «you/we», без восклицаний и точек с запятой (кроме мест, где без них нельзя), без слов-штампов из `prompts/system_prompt.md`; размер блока — в диапазоне ТЗ (инструмент проверит); весь текст не длиннее лимита страницы.
- Тексты других сайтов нужны только как фон: читать их, чтобы переписать иначе, не нужно; используй свою формулировку. Чем «индивидуальнее» подача (по `Page intent` в `01_brief.md` твоего запуска), тем меньше случайных совпадений.

=== b03 ===
The Longfu login works with the registered e-mail and password only, and the account holder is responsible for safeguarding these credentials. Access takes three steps:

1. Select Login on the website.
2. Enter the registered e-mail and password on the login screen.
3. Complete any security check and access the account.

A forgotten password is covered right after the steps.

=== b04 ===
A player who forgot the password requests a reset link to the registered e-mail, in three steps:

1. Choose Forgot Password on the login screen.
2. Request a reset link using the registered e-mail.
3. Follow the e-mailed instructions to set a new password.

Without access to that mailbox, contact support.

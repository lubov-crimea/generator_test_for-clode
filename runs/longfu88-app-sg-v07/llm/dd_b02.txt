Most phone trouble traces back to a few causes, and every one has a fast remedy, so the table covers four of them in a sensible order. Longfu88 support takes over where the table stops.

| Trouble | Remedy |
|---|---|
| Shortcut missing | Redo the setup in Chrome for Android or Safari for iOS |
| Page will not open | Reload and check the internet connection |
| Sign-in fails | Re-enter the e-mail address carefully, or use Forgot Password where the login is made |
| Still stuck | Ask support, which is on live chat 24/7 and on e-mail |
